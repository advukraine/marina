# Vitaliia beauty studio — демо-лендинг

Одностраничный сайт-демо для холодного питча. Чистый HTML + CSS + vanilla JS,
без сборки: `index.html` открывается двойным кликом.

```
index.html   разметка (все тексты через data-i18n)
style.css    mobile-first, брейкпоинты 768px и 1024px
app.js       galleryImages, translations, переключатель языка, лайтбокс
img/         фотографии
```

Страница закрыта от индексации: `<meta name="robots" content="noindex, nofollow">`.

## Как добавить фото в галерею

1. Положить файл в `img/` (имя `work-*.jpg` — работы, `interior-*.jpg` — интерьер).
2. Дописать имя файла в массив `galleryImages` в начале `app.js`.

Вёрстку менять не нужно: сетка сама раскладывается на 2 колонки на телефоне,
3 на планшете и 4 на десктопе при любом количестве фото. Если файла нет в `img/`,
плитка убирается сама.

## Языки

Польский по умолчанию, украинский — по кнопке PL / UA в шапке. Все тексты лежат
в объекте `translations` в `app.js`, выбор сохраняется в `localStorage`
(ключ `vbs-lang`). Цены в обоих языках одинаковые.

## Подключение домена

Сейчас в OG-тегах прописан адрес `boisterous-kringle-4b441f.netlify.app`.
При переезде на свой домен заменить его в трёх строках: `og:url`, `og:image`,
`twitter:image`. Адреса должны быть полными (`https://...`), относительные пути
мессенджеры не понимают. Это влияет только
на превью ссылки в Instagram, WhatsApp и Telegram; сам сайт работает и без этого.

Иконка вкладки — `img/favicon.png` (180×180), заглушка в фирменных цветах.
Если студия даст логотип в векторе, заменить файл, ничего в коде менять не надо.

## Переключение в публичный режим (при продаже)

Сейчас сайт намеренно скрыт от поиска — это демо. Чтобы открыть его для Google,
нужно снять **обе** заглушки, иначе страница не проиндексируется:

1. В `index.html` удалить строку `<meta name="robots" content="noindex, nofollow">`
   (над ней стоит комментарий с этой же инструкцией).
2. В `robots.txt` заменить `Disallow: /` на `Allow: /` либо удалить файл.

Порядок важен: если оставить `Disallow` в robots.txt, робот вообще не зайдёт на
страницу и не увидит, что `noindex` уже снят — сайт так и не появится в выдаче.

После этого: зарегистрировать сайт в Google Search Console, а студию —
в Google Business Profile (карточка на Картах даёт локальному салону больше
записей, чем позиции сайта).

## Разметка для Google

В `<head>` лежит блок JSON-LD типа `BeautySalon`: название, адрес, телефон,
часы работы, ссылка на Instagram и список услуг. На вид страницы он не влияет,
но помогает Google связать сайт с карточкой на Картах.

Держать в согласии с содержимым страницы: **телефон, адрес и часы работы**.
Если меняются на сайте — поменять и в разметке. Цены в разметку не выносил
специально, чтобы не поддерживать их в двух местах.

Стоит дописать координаты салона — как именно, сказано в комментарии над блоком.
Проверка разметки: search.google.com/test/rich-results
