# marina

Простой калькулятор в браузере — без сборки, зависимостей и установки.

## Запуск

Откройте `index.html` в браузере (двойной клик по файлу) или поднимите
локальный сервер:

```bash
npx serve .
```

## Возможности

- четыре действия: `+`, `−`, `×`, `÷`, цепочки вычислений (`2 + 3 × 4 =` считает слева направо)
- повторное нажатие `=` повторяет последнюю операцию
- процент: в сложении и вычитании — доля от первого операнда (`200 + 10 % =` даёт `220`), иначе просто деление на 100
- смена знака `±`, удаление последнего символа `⌫`, полный сброс `AC`
- деление на ноль показывает «Ошибка», следующая цифра начинает новый ввод
- разряды разделяются пробелами, результат округляется до 12 значащих цифр (`0.1 + 0.2` = `0.3`)
- очень большие и очень маленькие числа выводятся в экспоненциальной форме
- светлая и тёмная темы по настройке системы, адаптивная вёрстка

## Управление с клавиатуры

| Клавиши | Действие |
| --- | --- |
| `0`–`9`, `.`, `,` | ввод числа |
| `+` `-` `*` `/` | операция |
| `Enter`, `=` | вычислить |
| `Backspace` | удалить символ |
| `Esc`, `Delete` | сброс |
| `%` | процент |

## Структура

| Файл | Назначение |
| --- | --- |

| `styles.css` | оформление, темы, адаптив |
| `calculator.js` | состояние и логика вычислений |
